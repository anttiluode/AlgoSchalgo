What the learner actually learned

The learned classifier is a visible 4 × 4096 prototype matrix. A class score is normalized image similarity to one row. Learning here means averaging training examples into those four rows.

Candidate next transforms

Each candidate is applied temporarily to the current image. The page measures the resulting top-vs-second prototype margin and divides its gain by operation cost. The winning operation is the pulse. No learned gate decides this.

Execution trace

1 · IMAGE REMAINS STATE

The evolving object is still a 64×64 image. You can inspect every intermediate state directly instead of reverse-engineering anonymous activations.

2 · SUPPORT, NOT CONFIDENCE

The guard tracks the separation margin between the two best currently supported interpretations. When they collapse together, the machine has a specific reason to spend computation.

3 · PULSE = EXPLICIT WORK

A pulse is a named operation—recenter, rotate, sharpen, contrast—not a mysterious spike. Easy images can stop early; harder ones spend more stages.

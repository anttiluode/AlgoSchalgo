AlgoSchalgo · Perception Lab fusion

Prediction. Seeing. Support. Work. Surprise.

A visible perception cycle assembled from two old branches: predictive memory / surprise / finite ATP, and the newer observability idea. The system predicts the next image, sees a messy one, asks whether the current view actually supports a distinction, spends a finite computation budget on named image transforms only when needed, then shows exactly what remained surprising. The prediction never chooses the transform.

Visible transform trajectory — this is the actual work

Learned image memory P

Four visible 64×64 prototype rows. Learning = average centered training examples. Classification = normalized image similarity. No hidden feature space.

Learned temporal model T

T[next,current] in spirit: here shown as current row → next-class probability. It predicts what image should arrive next. It is not allowed to decide how to transform the observation.

Candidate paid transforms

Utility = increase in top-vs-second support margin ÷ ATP cost. Prediction agreement is deliberately absent, so the processor cannot massage an unexpected image into the expected one.

Execution trace

HIGH SURPRISE, LOW AMBIGUITY

The image is clear but violates the learned sequence. Correct response: report surprise and HOLD. Extra image processing would be wasted and could bias perception toward the prediction. Try Unexpected frame.

LOWER SURPRISE, HIGH AMBIGUITY

The world may be roughly what was predicted, but the noisy/shifted view fails to separate the current alternatives. Correct response: spend ATP on an explicit transform until support improves or budget runs out.

Provenance, cautiously stated. Perception Laboratory predates this repository and had many visual-memory / predictive-processing variants; earlier conversations associated part of that ancestry with a “Fable AI” idea, but the exact code continuity is not established. The accidental ECG workflow in fall 2025 was the actual birth point of the Geometric Neuron line. The predictive-cortex / ATP / surprise branch shown in the recent Perception Lab workflow is another evolution. AlgoSchalgo (August 2026) arrived from the separate observability/ambiguity route. This page is a deliberate fusion, not a claim that all of those were one continuous implementation.
